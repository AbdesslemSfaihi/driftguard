# Installation

## Requirements

pyconnect supports Python 3.10 and newer. It has no runtime dependencies.

## Install from PyPI

```bash
pip install pyconnect
```

## Install from source

```bash
git clone https://example.com/pyconnect.git
cd pyconnect
pip install -e .
```

## Verifying the install

```bash
python -c "import pyconnect; print('ok')"
```
